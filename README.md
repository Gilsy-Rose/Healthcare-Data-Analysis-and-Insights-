# Healthcare-Data-Analysis-and-Insights-
This project focuses on analyzing healthcare data to identify meaningful insights into patient health profiles, medical history, and healthcare costs. The analysis includes data cleaning, missing-value handling, data transformation, BMI and diabetes categorization, age calculation, and combining multiple healthcare tables using VLOOKUP. Pivot tables and visualizations were created to explore relationships between cancer history, smoking, surgeries, transplants, healthcare charges, hospital tiers, age, BMI, and HbA1C. An interactive dashboard was also developed with slicers for Weight Status and Diabetes Status to support easy comparison and data-driven insights.
